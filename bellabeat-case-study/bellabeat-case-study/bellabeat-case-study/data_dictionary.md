# Data Dictionary

## dailyActivity_merged.csv

| Column                   | Description                               |
| ------------------------ | ----------------------------------------- |
| Id                       | Unique user identifier                    |
| ActivityDate             | Date of the activity record               |
| TotalSteps               | Total number of steps recorded in one day |
| TotalDistance            | Total distance recorded                   |
| TrackerDistance          | Distance tracked by the device            |
| VeryActiveDistance       | Distance from very active movement        |
| ModeratelyActiveDistance | Distance from moderate activity           |
| LightActiveDistance      | Distance from light activity              |
| SedentaryActiveDistance  | Distance from sedentary activity          |
| VeryActiveMinutes        | Minutes of very active movement           |
| FairlyActiveMinutes      | Minutes of fairly active movement         |
| LightlyActiveMinutes     | Minutes of light activity                 |
| SedentaryMinutes         | Minutes spent sedentary                   |
| Calories                 | Calories burned                           |

## sleepDay_merged.csv

| Column             | Description                          |
| ------------------ | ------------------------------------ |
| Id                 | Unique user identifier               |
| SleepDay           | Date of the sleep record             |
| TotalSleepRecords  | Number of sleep records for that day |
| TotalMinutesAsleep | Total minutes asleep                 |
| TotalTimeInBed     | Total minutes spent in bed           |
