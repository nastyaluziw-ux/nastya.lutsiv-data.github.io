## Projects

### Bellabeat Case Study: Smart Device Usage Analysis

This project analyzes Fitbit smart device data to understand user activity, sleep behavior, and sedentary patterns.

The goal of this case study was to identify wellness trends and provide business recommendations for Bellabeat.

This project follows the full data analysis process:

- Ask
- Prepare
- Process
- Analyze
- Share
- Act

Tools used:

- Python
- pandas
- SQLite
- SQL
- matplotlib
- Jupyter Notebook
- GitHub

Main findings:

- Daily activity tracking had higher user coverage than sleep tracking.
- Sedentary time was negatively related to sleep duration.
- The correlation between sedentary hours and sleep hours was -0.60.
- Higher sedentary levels were associated with lower average sleep hours.

Business recommendations:

- Encourage users to track sleep more consistently.
- Use movement reminders and inactivity alerts to reduce long sedentary periods.
- Combine activity, sedentary behavior, and sleep insights in the app.
